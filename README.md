# Quiet Player for iPad

No captions. Original Quiet Player HTML-based interface, adapted for iPad Safari home screen use.

## Deploy

Repository Settings > Pages > Deploy from a branch > main / (root) > Save.

App URL: https://hsh385055-sketch.github.io/hsh385055-gmail.com/

## Data

Imported music is stored locally in IndexedDB, not uploaded to GitHub. Different origins do not share stored songs. Do not delete the installed web app or clear website data without exporting the original music files. iPadOS may limit playback transitions while the screen is locked.

## Security

The public GitHub repository contains only the static app UI. Never commit personal music files or login secrets.
